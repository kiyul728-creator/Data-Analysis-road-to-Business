# 1️⃣ 개념 정리 

## 01. 맷플롯립 기본 요소 알아보기

그래프를 꾸미는 것도 중요하지만, 필요한 정보가 잘 보이도록 표현하는 것이 중요하다.

### 그래프를 구성하는 요소

| 개념 | 배운 내용 |
| --- | --- |
| 피겨(Figure) | 그래프의 모든 구성 요소를 담는 전체 공간이다. `plt.figure()`로 만들 수 있다. |
| 서브플롯(Axes) | 피겨 안에서 각각의 그래프가 그려지는 영역이다. 하나의 피겨 안에 여러 개를 배치할 수 있다. |
| 축(Axis) | 데이터의 위치를 나타내는 기준이다. 2차원 그래프에는 가로 방향의 x축과 세로 방향의 y축이 있다. |
| 눈금과 레이블 | 눈금은 축에서 값의 위치를 표시하고, 레이블은 축의 이름 등을 나타낸다. |
| 마커(marker) | 데이터가 있는 위치를 동그라미나 별 같은 모양으로 표시한다. |

### 크기와 모양 바꾸기

- `figsize`는 그래프의 너비와 높이를 인치 단위로 지정한다. 예를 들어 `figsize=(9, 6)`은 너비 9인치, 높이 6인치라는 뜻이다.
- `dpi`는 1인치를 몇 개의 점으로 표현하는지를 나타낸다. 같은 `figsize`에서 DPI를 높이면 이미지의 픽셀 수가 늘어난다.
- `plt.rcParams`는 그래프의 기본 설정을 관리한다. `plt.rcParams['figure.dpi'] = 100`처럼 바꾸면 이후 그래프에도 적용된다.
- `marker`로 데이터 표시 모양을 바꿀 수 있다. `'o'`는 동그라미, `'*'`는 별, `'+'`는 덧셈 기호 모양이다.

### 여러 그래프 함께 그리기

`plt.subplots()`를 사용하면 하나의 피겨에 여러 그래프를 배치할 수 있다. 첫 번째 숫자는 행의 개수, 두 번째 숫자는 열의 개수이므로 `plt.subplots(1, 2)`는 그래프 두 개를 가로로 나란히 배치한다.

각 서브플롯에는 `set_title()`로 제목을, `set_xlabel()`과 `set_ylabel()`로 축 이름을 지정한다. 전체 공간인 피겨와 그 안의 개별 그래프 영역인 서브플롯을 구분하는 것이 중요하다.

## 02. 선 그래프와 막대 그래프 그리기

교재 302~324쪽에서는 연도별 발행 도서 개수로 선 그래프를, 주제별 도서 개수로 막대 그래프를 그리는 방법을 배웠다.

### 그래프에 사용할 데이터 준비하기

`value_counts()`는 각 값이 몇 번 등장하는지 세는 메서드이다. 교재에서는 발행년도별 도서 개수를 구하는 데 사용했다. 연도별 변화를 보려면 연도가 시간순으로 놓여야 하므로 `sort_index()`로 인덱스인 연도를 오름차순으로 정렬했다.

### 선 그래프와 막대 그래프 비교

| 그래프 | 사용하는 함수 | 특징 |
| --- | --- | --- |
| 선 그래프 | `plt.plot(x, y)` | 각 데이터 위치를 선으로 연결한다. 교재에서는 연도에 따른 발행 도서 개수의 변화를 나타냈다. |
| 세로 막대 그래프 | `plt.bar(x, y)` | 값의 크기를 막대 높이로 나타낸다. 교재에서는 주제별 도서 개수를 비교했다. |
| 가로 막대 그래프 | `plt.barh(y, width)` | 값의 크기를 가로 막대의 길이로 나타낸다. 세로 막대 그래프와 축의 역할이 달라진다. |

### 그래프에 필요한 정보 표시하기

- `plt.title()`은 그래프 제목을, `plt.xlabel()`과 `plt.ylabel()`은 각각 x축과 y축 이름을 지정한다.
- 선 그래프에서는 `marker`로 점의 모양, `linestyle`로 선의 모양, `color`로 색상을 바꿀 수 있다.
- `plt.xticks()`로 x축 눈금을 지정하고, `plt.annotate()`로 데이터 위치에 값이나 설명을 표시할 수 있다.
- 세로 막대의 두께는 `width`로, 가로 막대의 두께는 `height`로 조절한다.
- 가로 막대 그래프로 바꿀 때는 축 이름뿐 아니라 글자를 표시하는 x, y 좌표도 함께 바꾸어야 한다.

### 이미지 출력과 저장하기

| 함수 | 역할 |
| --- | --- |
| `plt.imread()` | 이미지 파일을 숫자들이 담긴 배열로 읽는다. |
| `plt.imshow()` | 읽은 이미지를 화면에 표시한다. |
| `plt.imsave()` | 이미지 배열을 파일로 저장한다. |
| `plt.savefig()` | 제목과 축 등을 포함한 그래프를 이미지 파일로 저장한다. |

교재에서는 그래프를 저장할 때 `plt.show()`보다 먼저 `plt.savefig()`를 실행했다. 이미지 자체를 저장하는 `imsave()`와 그래프를 저장하는 `savefig()`의 차이를 구분해야 한다.

**핵심 정리:** 데이터의 변화는 선 그래프로, 항목별 값의 크기는 막대 그래프로 나타낼 수 있다. 제목, 축 이름, 마커 등을 함께 표시하면 그래프의 의미를 더 쉽게 전달할 수 있다.

## 문제 1.

> **🧚Q. 다음 데이터를 이용하여 matplotlib으로 선그래프를 그리는 코드를 작성해주세요.**
- x = [1, 2, 3, 4, 5]
- y = [2, 4, 6, 8, 10]
> 조건은 아래와 같습니다.
```
1️⃣ 제목은 "Linear Trend"로 설정해주세요.
2️⃣ x축 이름은 "X values"로 설정해주세요.
3️⃣ y축 이름은 "Y values"로 설정해주세요.
4️⃣ 마커(marker)를 포함하여 선그래프를 그려주세요.
```

```python
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y, marker='o')
plt.title('Linear Trend')
plt.xlabel('X values')
plt.ylabel('Y values')
plt.show()
```
