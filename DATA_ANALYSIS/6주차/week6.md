# 1️⃣ 개념 정리 

## 01. 객체지향 API로 그래프 꾸미기

1. **Figure와 Axes**

   Figure는 그래프 전체를 담는 틀, Axes는 실제 그래프가 그려지는 영역이다. `fig, ax = plt.subplots()`로 두 객체를 만든다.

2. **객체지향 API 방식**

   `ax.plot()`, `ax.set_title()`처럼 객체의 메서드로 그래프를 그리거나 설정한다. 여러 그래프를 함께 그릴 때 수정할 대상을 구분하기 쉽다.

3. **한글 폰트와 기본 설정**

   한글을 출력하려면 한글 지원 폰트를 설치하고 `rcParams['font.family']`나 `plt.rc()`로 지정한다. 글자 크기와 그래프 해상도도 조절할 수 있다.

4. **산점도 마커 꾸미기**

   `scatter()`의 `s`는 크기, `c`는 색, `alpha`는 투명도를 조절한다. `edgecolors`와 `linewidths`로 테두리의 색과 두께를 바꾼다. 교재에서는 도서의 대출건수를 점의 크기와 색으로 표현했다.

5. **컬러맵과 컬러 막대**

   `cmap`은 값에 따른 색상 표현을 정하고, `fig.colorbar()`는 색과 수치의 대응 관계를 보여 준다. 마커 크기를 과하게 조절하면 차이가 부풀려 보일 수 있어 표현 기준을 함께 알려 주는 것이 좋다.

## 02. 맷플롯립의 고급 기능 배우기

1. **여러 개의 선 그래프와 범례**

   같은 Axes에서 `plot()`을 여러 번 호출하면 선 그래프를 겹쳐 그릴 수 있다. 각 선에 `label`을 지정하고 `legend()`로 범례를 추가한다. `set_xlim()`은 x축의 표시 범위를 정한다.

2. **데이터 집계와 피벗 테이블**

   `groupby()`는 같은 기준의 데이터를 묶어 집계하고, `pivot_table()`은 집계 기준을 행과 열로 나눈 표를 만든다. 피벗 테이블의 기본 집계 방식은 평균이므로 합계가 필요하면 따로 지정해야 한다.

3. **스택 영역 그래프**

   `stackplot()`으로 여러 선 그래프를 위로 쌓고 선 아래를 색으로 채운다. 항목별 크기와 전체 합계의 변화를 함께 볼 수 있다. 개별 항목의 크기는 위쪽 경계의 높이가 아니라 해당 영역의 두께로 읽는다.

4. **스택 막대 그래프**

   막대를 위로 쌓아 항목별 크기를 비교한다. 교재에서는 `cumsum()`으로 누적 합을 구한 뒤 큰 막대부터 그렸다. 판다스의 `plot.bar(stacked=True)`를 사용하면 미리 누적 합을 계산하지 않아도 된다.

5. **원 그래프**

   `pie()`로 전체에서 각 항목이 차지하는 비율을 나타낸다. `autopct`는 비율 표시, `startangle`은 시작 각도 설정, `explode`는 특정 조각 강조에 사용한다. 일부 항목만 선택했다면 비율의 기준도 선택한 항목들의 합계가 된다.

6. **여러 그래프를 배치하는 서브플롯**

   `plt.subplots(2, 2)`로 하나의 Figure에 네 개의 그래프를 배치한다. `axes[0, 0]`처럼 행과 열의 위치로 각 그래프를 지정한다. 같은 데이터를 여러 종류의 그래프로 비교할 때 유용하다.
