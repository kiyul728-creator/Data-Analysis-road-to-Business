## 01.

```
개념 이름: JOIN
개념 설명: 두개 이상의 테이블을 특정 키 값으로 결합하여 새로운 테이블을 만드는 것을 JOIN이라고 한다.
예시 쿼리:

SELECT
  tp.id,
  tp.trainer_id,
  tp.pokemon_id,
  -- t.id, # id_1 : id라는 결과가 중복이여서 이렇게 됨
  t.age,
  t.hometown
FROM basic.trainer_pokemon AS tp
LEFT JOIN basic.trainer AS t
ON tp.trainer_id = t.id ;
```

## 02.

```
개념 이름: LEFT JOIN
개념 설명: 왼쪽 테이블을 기준값으로 설정하여 오른쪽 테이블을 왼쪽 테이블과 결합하는것 따라서 왼쪽 테이블의 행은 모두 나오고 왼쪽 테이블의 존재하지만 오른쪽 테이블에 없는 행은 NULL값이 나온다 
예시 쿼리:

SELECT
  tp.*,
  t.*
FROM basic.trainer_pokemon AS tp
LEFT JOIN basic.trainer AS t
ON tp.trainer_id = t.id ;
```
